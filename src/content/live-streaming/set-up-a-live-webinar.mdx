# How do I set up a live webinar?

You can use Cinema8 Live to run webinars with invited speakers and an audience watching through the Cinema8 watch page. Set up your Live event, then configure the Greenroom, audience features, recording, and guest invitations for your webinar.

<Callout type="info">
The Cinema8 watch page, recording, Comments, Q&A, and polls are available on [**Live Scale and Live Enterprise plans**](https://cinema8.com/live-streaming-pricing).
</Callout>

<Steps>

### Step 1: Create your webinar event

Start by creating a new Live event and setting its title and schedule. Follow the steps in [**How do I set up a live stream?**](/live-streaming/set-up-a-live-stream) to create the event and configure the basic settings.

There is no separate webinar event type. A webinar uses a Cinema8 Live event with the features you need for speakers and audience participation.

### Step 2: Set up the Greenroom

Turn on **Greenroom** when setting up your event and choose how many minutes before the scheduled start time guests can join.

This gives invited speakers time to join before the webinar begins and prepare before appearing on stage.

### Step 3: Enable recording

Turn **Recording enabled** on if you want your webinar to be available after the live broadcast.

When the webinar ends, Cinema8 processes the recording and publishes the replay to the same watch-page link used for the live event. The recording is also added to your Cinema8 video library, where you can edit it and [add interactivity](https://cinema8.com/interactive-video).

Recording is available on **Live Scale and Live Enterprise plans**.

### Step 4: Add the Cinema8 watch page

During the **Distribution** step, add **Cinema8** as a destination.

The watch page gives attendees one link for the webinar. Before the event, it displays a countdown. During the event, attendees can watch the broadcast and use the audience features you have enabled. If recording is enabled, the same URL becomes the replay link after processing.

### Step 5: Set up audience features

Choose which audience features you want to use during the webinar. Go to **Event > Overview > Edit > Features** and enable the features you need:

- **Comments:** Let attendees communicate during the webinar.
- **Q&A:** Collect moderated questions from attendees. Questions can be approved, answered, pinned, hidden, or deleted before they appear to the audience.
- **Polls:** Create questions for attendees to answer during the webinar, with options for multiple selections and an automatic closing timer.

These features are available through the Cinema8 watch page on **Live Scale and Live Enterprise plans**.

### Step 6: Invite more speakers

Add your speakers as guests during the **Distribution** step, or invite them later from the Studio.

Each guest receives an invitation link that lets them join from their browser without creating a Cinema8 account or installing software. Guest links remain valid for seven days.

### Step 7: Review your webinar

Before entering the Studio, review your event settings, including the schedule, Greenroom, recording, destination, and invited guests.

You can then go back to the dashboard or select **Enter Studio**. Entering the Studio does not start your webinar. Nothing is broadcast until you select **Go live**.

### Step 8: Prepare in the Studio

Before the webinar begins, use the Studio to check your camera and microphone, prepare the stage, and make sure your speakers are ready.

You can also set your layout and prepare any logos, overlays, backgrounds, screen shares, or other media you plan to use during the webinar.

</Steps>

## What happens next?

Once your webinar is set up, make sure attendees know where and when to join.
